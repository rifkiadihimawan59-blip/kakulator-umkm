# Kalkulator Keuangan & Keuntungan UKM

Aplikasi berbasis web sederhana untuk membantu pelaku UMKM menghitung Harga Pokok Penjualan (HPP), estimasi keuntungan bersih, dan rekomendasi harga jual per unit secara praktis.

## Fitur Utama
- Input biaya modal bahan baku dan operasional.
- Perhitungan HPP per unit otomatis.
- Proyeksi harga jual berdasarkan persentase margin laba.

## Teknologi
- HTML5
- Tailwind CSS (via CDN)
- JavaScript Vanilla
